ABYSHKA.AI v23 — УСТАНОВКА НА iPAD И iPHONE

1. Распакуй ZIP. Внутри находятся index.html, manifest.webmanifest, service-worker.js и папка icons.
2. Создай бесплатный аккаунт на github.com (если его ещё нет).
3. Создай новый ПУБЛИЧНЫЙ репозиторий, например abyshka-ai.
4. Загрузи в корень репозитория ВСЕ файлы из распакованной папки, включая папку icons. Не загружай только ZIP.
5. В репозитории открой Settings > Pages. Выбери Deploy from a branch, branch main, folder /(root), затем Save.
6. Дождись публикации. Ссылка будет похожа на https://ИМЯ.github.io/abyshka-ai/
7. На iPad открой ссылку в Safari, нажми Поделиться > На экран «Домой» > Добавить.
8. Отправь эту же ссылку друзьям: они тоже смогут добавить приложение на главный экран.

ВАЖНО:
- Не загружай в репозиторий пароли, API-ключи и личные переписки. Репозиторий публичный.
- Чаты сохраняются локально на каждом устройстве и не синхронизируются автоматически.
- Офлайн-режим работает после первого успешного открытия сайта; интернет-поиск и API требуют подключения.
- Safari не разрешает произвольный доступ к другим вкладкам.
- Для обновления файлов на сайте замени их в репозитории. Для гарантированного обновления офлайн-кеша нужно менять CACHE_NAME в service-worker.js.
