✦ Abyshka.ai
Офлайн-режим • База знаний+

Поиск открывает гостиницы на внешних сайтах; цены, звёзды и наличие проверяй там. Даты и фильтры передаются там, где это поддерживается.

Фильтры и поворот работают без интернета. Если настроен API редактирования, можно также описать изменения словами и отправить фото модели.

Ответы:
Больше ответов на вопросы о здоровье, играх и учёбе. Офлайн-справочник не заменяет полноценную нейросеть.
Без интернета доступны встроенные знания, красивые рисунки и планировщик поездок. Для сложных и актуальных данных можно подключить внешнюю модель через ⚙.

⚙ Мозг Abyshka.ai

Приложение работает офлайн сразу после открытия. Для более сильных ответов можно подключить совместимый API.

Поиск использует открытую Википедию, если браузер разрешает соединение. Это не чтение вкладок Safari и не универсальный поиск по всему интернету.

⚠️ В браузерной демо-версии ключ используется напрямую в запросе. Для публичного сайта нужен свой защищённый сервер.
